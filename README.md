# 🩸 Blood Need - Advanced Java Mini Project

> A professional blood donation notification platform built with HTML, CSS, and JavaScript.

## ✨ Features

- 🩸 **Popup Bot** - AI-powered chatbot for blood donor matching
- 🌐 **Bilingual Support** - English & Bangla language toggle
- 🌙 **Day/Night Theme** - Toggle between light and dark modes
- 📱 **Multi-Device** - Auto-sync across all devices
- 🚨 **Emergency Alerts** - Pop-up emergency notifications
- 📊 **Dashboard** - Stats, charts, requests, activity feed
- 👤 **Profile Management** - Personal info, contact, settings
- 🔔 **Notification Bell** - Real-time notifications
- ⚡ **Instant Matching** - Find compatible donors quickly

## 📁 Project Structure


## 🚀 Quick Start

1. Clone the repository
2. Open `index.html` in your browser
3. Login with any email/password
4. Explore the dashboard and profile
